# ⚡ 大学电路作业解决方案——线性直流电路绘制与仿真工具

一个基于 **Python + Tkinter** 的图形化线性直流电路编辑器与求解器。  
支持拖拽放置元件、连线、设置参数，自动生成网表，并调用改进节点法（MNA）求解。  
求解完成后，节点电压和元件电流会直接标注在电路图上。
该项目非常适合于完成、检查大学电路的部分作业。

---


# ⚡ Linear DC Circuit Editor and Simulator

A graphical linear DC circuit editor and solver based on **Python + Tkinter**.  
It supports drag-and-drop placement, wiring, parameter editing, automatic netlist generation, and solves using **Modified Nodal Analysis (MNA)**.  
After solving, node voltages and element currents are annotated directly on the schematic.

---

## ✨ 功能特性

- **图形化绘制**：拖拽放置电阻、独立电压源、独立电流源、四种受控源、节点、地、0V 电流探针。
- **自动节点编号**：基于并查集合并相连引脚，地节点固定为 `0`，其余节点自动分配。
- **连线与交叉**：支持导线连接、交叉不连、删除导线不影响两端元件。
- **参数编辑**：右侧属性面板实时修改元件名称、阻值、电压、增益等。
- **受控源支持**：
  - VCVS / VCCS：控制量可选任意两端元件的端电压（包括电阻、电压源等）。
  - CCVS / CCCS：控制量必须为电压源支路电流（可串联 0V 探针测量电阻电流）。
- **撤销 / 重做**：最多 10 步，支持 `Ctrl+Z` / `Ctrl+Y`。
- **一键求解**：点击“求解”即可在画布上显示所有节点电压和元件电流。
- **导出网表**：可将电路保存为 `.txt` 网表文件，供其他工具使用。
- **纯 Python 实现**：仅依赖 `numpy` 和 `scipy`，跨平台（主要在 Windows 下测试）。

## 🎮 快速开始

1. 启动程序后，顶部工具栏选择元件类型。
2. 在画布网格上点击放置元件。
3. 使用“选择”模式移动元件，使用“连线”模式连接引脚。
4. 选中元件，在右侧属性面板修改参数。
5. 点击“求解”，节点电压（红色）和元件电流（紫色）会显示在图上。
6. 如需保存电路，点击“导出网表”。

### 注意事项
**一定要记住要放置接地点！**
**一定要注意先放置节点再在上面接线。**

## 📖 使用指南

### 放置与编辑
- **放置**：点击工具栏按钮 → 在画布上单击。
- **移动**：选择模式下拖动元件。
- **旋转**：选中元件后点击“旋转”按钮（每次 90°）。
- **删除**：选中元件或导线，按 `Delete` 键或点击“删除”按钮。

### 连线
- 点击“连线”按钮，然后依次点击两个引脚。
- 导线交叉但未连接时，即表示不连通。
- 如需在交叉处连接，可放置一个“节点”元件，并将导线连到该节点。

### 受控源控制量设置
- **VCVS / VCCS**：在属性面板“控制元件”下拉框中选择任意两端元件（如电阻），程序取其两端电压作为控制量。
- **CCVS / CCCS**：在属性面板“控制电压源”下拉框中选择一个电压源或 0V 探针。若需控制电阻电流，请在该电阻支路中串联一个 **0V 探针**。

### 求解与显示
- 点击“求解”后，程序自动生成网表并调用 MNA 求解。
- 节点电压以红色标注在节点附近，元件电流以紫色标注在元件下方。
- 点击“清除结果”可移除标注。

### 导出网表
- 点击“导出网表”，选择保存路径，生成 `.txt` 文件。
- 网表格式兼容本项目的求解器，也可用于其他 SPICE 类工具（需调整格式）。

## 📄 网表格式

网表为纯文本，每行一个元件，以 `#` 或 `*` 开头的行为注释。  
元件名称首字母决定类型：

| 类型 | 首字母 | 格式 | 示例 |
|------|--------|------|------|
| 电阻 | `R` | `R名称 节点1 节点2 阻值` | `R1 1 2 10` |
| 独立电压源 | `V` | `V名称 正极 负极 电压值` | `V1 1 0 5` |
| 独立电流源 | `I` | `I名称 流出节点 流入节点 电流值` | `I1 2 0 0.1` |
| VCVS | `E` | `E名称 输出正 输出负 控制正 控制负 增益` | `E1 3 0 1 0 2` |
| VCCS | `G` | `G名称 输出正 输出负 控制正 控制负 跨导` | `G1 4 0 1 0 0.5` |
| CCVS | `H` | `H名称 输出正 输出负 控制电压源名称 增益` | `H1 5 0 V1 3` |
| CCCS | `F` | `F名称 输出正 输出负 控制电压源名称 增益` | `F1 6 0 V1 2` |

- 节点 `0` 为参考地。
- 电压源支路电流方向：从正极流向负极。
- 电流源方向：从第一个节点流向第二个节点。
- 电流控制源的控制量必须引用一个**电压源支路名称**（如 `V1` 或 0V 探针）。
